# Homepage — Selected Reference

**Status:** Selected  
**Design direction:** The Forbidden Manuscript, combined with the ruined cathedral and crimson eclipse.

## Selected mockup
The approved homepage mockup was generated in this conversation on 2026-10-25. The rendered image is currently held in the conversation; it has not yet been committed as a binary asset in this repository.

## Visual composition
- **Background:** towering ruined gothic cathedral, distant spires, fog, and a crimson eclipse.
- **Branding:** large, ornate DREADVEIL title and the tagline: “When the gods fell silent, the dice began to whisper.”
- **Primary navigation:** three prominent parchment/engraved options — New Expedition, The Descent, Continue Run.
- **Adventurer panel:** character portrait and profile on the right.
- **Dice arsenal:** six tactile polyhedral dice shown as physical objects.
- **Foreground:** open illustrated occult grimoire, annotated sketches, sigils, candlelight, and relics.
- **Bottom navigation:** Home, Bestiary, Dice Arsenal, Chronicles, Settings.

## Design rules
- Preserve the image as the canonical homepage reference.
- Keep the primary action visually dominant; avoid allowing the foreground book to compete with the main menu.
- Maintain readable labels and clear interaction hierarchy.
- Keep atmospheric art rich but ensure panels, controls, and navigation remain usable.
- Future refinements should build on this direction rather than replace it without explicit user approval.

## Implementation status
No implementation changes have been made as part of selecting this reference. The mockup is not pixel-perfect source code.
