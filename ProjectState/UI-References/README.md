## Reference workflow
1. Generate a mockup for the current screen.
2. Wait for explicit user selection/approval.
3. Record the selected image, decisions, and any follow-up refinements in that screen's folder.
4. Implement only after the user explicitly asks for implementation.
5. Preserve previously selected references when designing later screens.

## Global visual direction
- Gothic dark fantasy, occult symbolism, illustrated bestiary and forbidden-manuscript motifs.
- Obsidian, aged vellum, tarnished gold, blood-wine red, and restrained rotten green.
- Physical-feeling materials: parchment, engraved metal, stone, leather, candles, and tactile dice.
- Cinematic atmosphere, but functional text and controls must remain readable.
- Avoid modern dashboard styling, neon, excessive skull motifs, and decorative clutter that harms usability.

Mockups are visual references, not implementation specifications. Preserve existing functionality when implementation is later requested.
